# Ascendum_demo
### ALL ASCENDUM DEMOS code will be here

Required Python version 3.11.0

1. Download Ollama
   https://ollama.com/download/windows


2. After Installing run this command on command to install "llama3.2":

   ollama pull llama3.2 (Install in your system by default location, any specific location is not required.)

   NOTE: before running the application, Ollama should be running.


3. To Create an virtual_environment, Use this command:
   python -m venv '<env_name>'


4. To install requirements, run this command:
   pip install -r requirements.txt


5. To run this application, Use this command
   streamlit run '<app_name>.py'
