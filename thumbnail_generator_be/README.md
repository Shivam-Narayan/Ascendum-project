# Dangal Project

This project requires Python 3.11.0 and a virtual environment to run properly.

## Prerequisites

- Python 3.11.0 must be installed on your system.

## Setup Instructions

Follow the steps below to set up and run the project:

### 1. Install Python 3.11.0

Ensure you have Python 3.11.0 installed. You can download it from the official [Python website](https://www.python.org/downloads/release/python-3110/).

### 2. Create a Virtual Environment

Create a virtual environment named `dangal_env` using the following command:


python -m venv dangal_env

To Activate the Virtual Environment

On Windows:

dangal_env\Scripts\activate

On macOS/Linux:

source dangal_env/bin/activate

Run Command to install all the Requirements or Dependencies

python run.py
    OR
pip install -r requirements_server.txt

To start the Django development server

python manage.py runserver
