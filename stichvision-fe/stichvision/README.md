# React App - Quick Start Guide

This guide will help you set up and run the project in just a few steps.

## 🚀 Steps to Run the Project

### Clone the Repository
git clone https://github.com/sourcebitsllc/Ascendum_demo.git


### Navigate into the Project Directory
cd stichvision-fe


### Install Dependencies
npm install


### Start the Development Server
npm start


### View in BrowserOpen your browser and go to:
http://localhost:3000
